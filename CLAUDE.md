## Repository layout

Static HTML pages, one folder per page (`<name>/index.html`, plus assets such as `img/`). The root `index.html` is the Pocket Snake game. The site is published with GitHub Pages from `main`, root folder, at https://shrivardhan232006.github.io/claude-cloud-session/.

## Rule: keep README.md in sync

Every time a new HTML page is added, add a row to the table in `README.md` with the page name, its GitHub Pages live link (`https://shrivardhan232006.github.io/claude-cloud-session/<folder>/`), and its source path. Commit the README change together with the new page.
